Időpontfoglaló rendszer

Ez a projekt egy webes klienssel és ASP.NET Core backenddel megvalósított időpontfoglaló rendszer.

A dokumentáció tartalmazza:
- bevezetés, célok, témaválasztás,
- csapatmunka és verziókövetés,
- felhasználói telepítési és használati leírás,
- fejlesztői architektúra és adatbázismodell,
- tesztelés, hibajavítási napló, összegzés, továbbfejlesztési lehetőségek.
